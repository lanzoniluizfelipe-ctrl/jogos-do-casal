# Jogos do Casal 4.2.1

App de jogos íntimos para casais (+18).

## Link de acesso (navegador)

**https://lanzoniluizfelipe-ctrl.github.io/jogos-do-casal/**

(Ative o GitHub Pages em Settings → Pages → Source: Deploy from branch `main`, pasta `/`.)

## Instalar no celular

1. Abra o link no Chrome (Android) ou Safari (iPhone)
2. Menu → **Adicionar à tela inicial** / **Instalar app**

## Sincronização

No app: **Conta e nuvem** ou **Configurações** → configure um projeto Supabase gratuito para sincronizar entre celular e computador.
